# BigMart Sales - End-to-End Azure Data Engineering Pipeline

## 📌 Project Overview

This project demonstrates an end-to-end data engineering pipeline built using Microsoft Azure.

The project takes BigMart sales data from a CSV file, loads it into Azure Data Lake Storage Gen2, transforms the data using Azure Data Factory Mapping Data Flow, stores the processed data back in ADLS Gen2, and finally loads the transformed data into an Azure SQL Database.

The main purpose of this project was to understand how a real-world ETL/ELT pipeline works using Azure services.

🐛 Problems Faced During Development

This project involved several real-world Azure Data Factory errors.

1. HTTP 404 Error

Error:

HttpRequestFailedWithClientError
404 NotFound
Cause

The HTTP/GitHub URL or file path was incorrect.

Learning

Always verify the raw GitHub file URL and dataset configuration.

2. JSON Invalid Data Format

Error:

JsonInvalidDataFormat
Error parsing Infinity value
Cause

The source was being interpreted as JSON even though the source file was not valid JSON for that configuration.

Learning

The dataset format must match the actual source file.

3. ADLS PathNotFound

Example:

PathNotFound

ADF was looking for:

Bigmart/Output_BigMartSales.csv

but the Data Flow had actually generated:

Bigmart/part-00000-xxxxxxxx-c000.csv
Learning

Mapping Data Flow output filenames may be automatically generated.

Always check the actual ADLS output path before configuring the next activity.

4. SQL Connection Error

Example:

SqlFailedToConnect
Login failed
Possible causes
Incorrect credentials
Incorrect database
Firewall configuration
Incorrect server endpoint
Learning

Azure SQL connectivity requires correct server, database, authentication, credentials, and firewall configuration.

5. SQL Invalid Object Name

Example:

Invalid object name 'dbo.BigMartSummary'
Cause

The table did not exist in the database being used by the linked service.

Learning

Always confirm:

Server
    ↓
Database
    ↓
Schema
    ↓
Table
6. Empty SQL Table

At one point:

SELECT COUNT(*) FROM dbo.BigMartSummary;

returned:

0
Cause

The final Copy activity had failed because it was trying to read a file that did not exist.

After correcting the ADLS path, the final pipeline could load the processed data.

Learning

When a SQL table is empty, check the pipeline execution and source rows before assuming the SQL table is broken.
